Astra Rebuilds the Berlin State Library

INSIGHTS

GPT-6 Astra got the structure and layout right: the shelves, galleries, stair and service desk are all in proportion and in place. What it missed is the atmosphere, from the warm orange carpet to the glow of the wood and the rippled art glass.

PROMPT

Show the full prompt›
You are a senior expert in architectural surveying, photogrammetry and Blender architectural visualization.

Task: Using the reference photos I upload, rebuild the Staatsbibliothek zu Berlin (Berlin State Library) as a 3D architectural model in Blender, as accurately as possible.

Important: the Staatsbibliothek zu Berlin has more than one site, including the historic Unter den Linden building and the Potsdamer Straße building. First confirm from the photos which building this is. Do not mix features from different sites.

Goals:
- Recreate the appearance, massing, facade proportions and spatial relationships visible in the photos.
- Build a Blender scene at real-world scale, clearly structured and editable.
- The model is for architectural visualization, not construction drawings or engineering surveys.
- Don't just give me a plan or a tutorial. Operate Blender directly, then create and verify the final model.

Reference principles:
1. The uploaded photos are the primary visual evidence.
2. First number every photo and work out its shooting direction, camera height, perspective and likely focal length.
3. Extract the building outline, floor heights, column grid, window rhythm, entrance positions, roofline, wall thickness and repeated elements.
4. If a photo shows people, doors, steps, vehicles or standard components, use them to estimate scale.
5. For backs, roofs or hidden areas the photos can't show, build only a simplified, plausible structure.
6. Don't add decoration the photos give no evidence for.
7. Record every assumption in assumptions.md with a confidence level: high, medium or low.
8. If exact dimensions are missing, keep going with reasonable architectural proportions instead of stopping to wait. Ask me one short question only if the answer would fundamentally change the building's structure.

Modeling process:

Phase 1: Photo analysis
- Confirm the exact site and architectural style.
- Create reference_analysis.md.
- List the facade, perspective and scale information each photo can support.
- Separate what is certain, what is a reasonable inference and what can't be determined.

Phase 2: Scale and massing
- Set Blender units to meters.
- Build the main interior.
- Finish a low-detail blockout first.
- Calibrate perspective using vanishing points and the building's horizontal and vertical lines.

Phase 3: Architectural detail
- Build walls, floor slabs, window and door openings, columns, beams, steps and cornices following real construction logic.
- Use instances, Array or Geometry Nodes for windows, facade panels, columns and other repeated elements.
- Keep clean topology, correct normals, consistent naming and a clear hierarchy.
- Separate the main structure, facade, glass, metal, roof, ground and environment.
- Avoid unnecessary polygon counts: close-up elements can be more detailed, distant ones simplified.

Phase 4: Materials
- Create physically based PBR materials from the photos.
- Focus on matching the color, roughness, reflection and texture scale of concrete, stone, brick, glass, metal and wood.
- Don't paint shadows or highlights into the base color maps.
- UV scale must match the real building's scale.
- Glass needs realistic thickness, reflection and transparency.

Phase 5: Verification and iteration
- Set up a matching camera for each main reference photo.
- Render the model from each matching view and compare it with the original, item by item:
- Building outline
- Length, width and height proportions
- Floor lines
- Window and column rhythm
- Entrance and step positions
- Roofline
- Perspective and camera height
- Material brightness and color
- Output side-by-side comparison images.
- Create qa_report.md recording the problems found and how they were fixed.
- Complete at least three render-check-fix rounds.
- Also output untextured Solid View renders from the front, back, left, right, top and an axonometric view to check the geometry.
- Check for and fix floating objects, intersections, duplicate faces, flipped normals, broken instances, obvious scale errors and missing materials.

Files and versions:
- Don't overwrite earlier work.
- Save these stage files:
- 01_blockout.blend
- 02_architecture.blend
- 03_materials.blend
- 04_final.blend
- Save reusable Blender Python scripts in scripts/.
- Keep all textures in textures/.
- Save test and final renders in renders/.
- Use relative paths so textures aren't lost if the project moves.

Final deliverables:
1. A complete, editable 04_final.blend
2. A GLB version
3. An FBX version
4. The Blender Python modeling scripts
5. Renders from six standard views
6. At least three views matched to reference photos
7. One high-quality hero render
8. reference_analysis.md
9. assumptions.md
10. qa_report.md

Acceptance criteria:
- At first glance it is clearly recognizable as the Staatsbibliothek zu Berlin in the reference photos.
- The main outline, facade proportions, window rhythm and entrance relationships match the photos.
- The model uses real-world scale with no obvious structural conflicts.
- Every major element can be selected and edited on its own.
- Materials hold a sensible scale both up close and from a distance.
- The final file loses no textures or references when reopened.
- "A model has been generated" is not the bar for done. You must actually open the file, check the renders and fix obvious problems.

Now analyze all the reference photos, confirm the site and set up a reconstruction plan, then start building the model in Blender right away and keep working until all the deliverables above are done.
