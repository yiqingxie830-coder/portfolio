Dynamic LLM Routing

📍 Los Angeles, CA · Oct 2026 – Nov 2026

USC Machine Learning course project on cost- and preference-aware model selection.

Problem Definition

The strong model costs about 6.1x the cheap model per request but wins only 62% of user preference votes; studied routing each request by its content to balance inference cost against user preference.

Evaluation Framework

Used 101K LMArena user preference votes and Bradley-Terry ratings to split strong and weak tiers; split data by prompt group, pre-registered success criteria, and measured routing with APGR.

Router Modeling

An embedding-based router raised test-set APGR from 0.529 to 0.612; 7 LLM-generated semantic tags came close to that result using only about 6,700 votes.

Cost-Effectiveness

Designed a two-layer routing policy combining price rules with an embedding-based router, capturing half of the strong model’s quality gain while cutting cost per 1,000 requests.
